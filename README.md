# OnePlus SM8550 common (12R / Ace 3)

Shared configuration for the OnePlus SM8550 pair (`aston` / `astonc`).

Branch **`17`** = the Android 17 build tree (this is what the ROM builds against).
The plain LineageOS-24 counterpart of each repo is available upstream.

Blobs: [gitlab](https://gitlab.com/EXlipsecore/proprietary_vendor_oneplus_sm8550-common)
